## [0.16.4] - 2026-11-17

### Changed

- Zinder now certifies Zebra 7.1.0 and parses blocks with zebra-chain 16.0.0, the release Zebra 7.1.0 uses. Zebra 7.0.0 is expected to keep working but is no longer tested; upgrade to 7.1.0 for its security fixes, without a store rebuild. When Zebra 7.1.0 cannot reassemble a damaged stored block, ingest readiness reports `node_unavailable` with class `capability_missing` instead of a changed chain, and query returns `NODE_CAPABILITY_MISSING`. A refused node credential now logs a reason that names HTTP 401. ([#239](https://github.com/ZcashFoundation/zinder/pull/239))

### Fixed

- Ingest no longer exits and restarts when the node switches to a sibling block between ingest's block read and its tree-state read; it reads the tree state by block hash, observes the node again, and logs a `canonical_source_recovery` warning. `zinder_ingest_canonical_source_recoveries_total` now carries a `failure_class` label, and a tree state that contradicts its own block still stops ingest. ([#236](https://github.com/ZcashFoundation/zinder/pull/236))
